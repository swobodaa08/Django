2. Vytvorenie projektu:
	django-admin startproject nazov_projektu

3. Nastavenie slovenčiny pre projekt (nazov projektu/settings.py):

	LANGUAGE_CODE = 'sk'
	TIME_ZONE = 'Europe/Bratislava'
	
4. Spustenie vývojového servera:
	python.exe .\manage.py runserver
	beží na adrese http://127.0.0.1:8000

5. Vytvorenie aplikácie:
	python.exe .\manage.py startapp nazov_aplikacie

6. Registrácia aplikácie do projektu (nazov projektu/settings.py):
	
	INSTALLED_APPS = [
    	'django.contrib.admin',
    	'django.contrib.auth',
    	'django.contrib.contenttypes',
    	'django.contrib.sessions',
    	'django.contrib.messages',
    	'django.contrib.staticfiles',
   	 'nazov_aplikacie',
	]

7. Vytvorenie jednoduchého views (nazov aplikacie/views.py):
	
	from django.shortcuts import render, Httpresponse

	def index(request):
    		return Httpresponse('Hello World!!!')

8. Vytvorenie urlpattern
8.1 nazov_projektu/urls.py 
	
	urlpatterns = [
    		path('admin/', admin.site.urls),
    		path('skola/', include('nazov_aplikacie.urls'))
	]

8.2 vytvoriť súbor urls.py v priečinku aplikacie

	from django.urls import path
	from . import views

	urlpatterns = [
		path('', views.index, name='index'), # views.index - index je nazov funkcie vo views.py
	]

9. Templates
9.1 vytvorenie Template
	- vytvoriť v priečinku aplikacie priečinok templates/nazov_aplikacie
	- v tomto priečinku vytvoriť html subor (napriklad index.html)
9.2 upraviť views.py tak aby používal templates
